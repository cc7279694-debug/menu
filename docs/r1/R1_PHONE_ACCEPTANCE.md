# R1 手机集中验收说明（准备稿）

目前还没有长期签名正式候选 APK。以下步骤须等签名保管和构建门禁通过后
再执行；不要安装未签名中间产物，也不要把 cloudpreview 当作正式候选。

1. 保留原版 v23，不卸载、不清数据。安装届时交付的独立候选版，包名应为
   `app.recipio.local.next`。它应与旧版并存，首次打开为空库属于预期。
2. 先用测试菜谱体验三种主题的保存、重开，封面、编辑、烹饪和备份入口。
3. 只有在你明确同意迁移真实数据后，才从原版导出完整 `.recipio` 备份。
   它未加密，含个人内容，应仅保留本地，不发给聊天、GitHub 或 CI。
4. 新版选择备份后，先对照预览数量。取消应不改变数据。确认恢复会完整
   替换新版当前数据，不是合并；新版若已有重要内容，先另做安全备份。
5. 恢复后对照菜谱、封面/步骤图、历史旧图、修改历史和烹饪记录，抽查中文、
   时间、顺序和离线冷启动。原版和源备份继续保留。
6. 后续收到相同长期证书、递增版本号的新 APK 时，直接覆盖安装新版。
   不先卸载；确认新版已有菜谱和图片仍在。签名不一致时停止安装，反馈错误，
   不以卸载或清数据解决。

当前未要求你执行任何导出、恢复、卸载或手机测试。候选交付后再补实际版本、
证书指纹及 APK SHA256。本说明不是实际迁移/升级通过证据。
