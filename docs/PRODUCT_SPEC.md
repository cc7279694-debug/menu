# 谱序 RECIPIO 产品基线

依据用户提供的 `E:\CODEX\RECIPIO_CODEX_APK_EXECUTION_PROMPT.md`；2026-10-03 先完成日常库浏览器实现，随后用户要求 APK-1 Android Native Acceptance Gate。产品范围不变，只补齐原生验收，保留已验证底座，不重复技术路线比较。

## 定位和导航

个人菜谱库。先找已有做法，再主动找新菜。首页／我的菜谱／设置；首页右上角新增。首页突出搜索和最近加入，库页面全部菜谱及耗时筛选。按创建时间倒序，编辑不改变加入时间，固定 ID 次级排序。搜索菜名和食材；不做推荐或 AI 搜索。

首页卡片图片、菜名、耗时、约 kcal/份和准备提示；做过时间仅在未来真的有明确完成记录时显示。库卡片只图片、菜名和耗时。未知耗时仅在全部筛选出现；30 分钟内、超过 30 至 60、超过 60 不重叠。

## 内容

只填非空菜名即可成为普通菜谱，无草稿/完成度/待完善队列。同名允许；以后补做法仍用同一 ID。食材保存实际用量，不自动按份数缩放。详情完整步骤默认，提前准备和关键事项在做菜前显示；关键事项可关联步骤重复提示。准备时间不明保留原文字，不虚构倒计时或提醒。做菜耗时独立记录，不盲目累加提前准备和并行事项。

图片为本地封面及步骤参考，不存视频片段。热量弱辅助，用“约”，份数未知不推算整道热量；信息变化须核对已有参考值。

## 记录和安全

只有明确完成才记做过，浏览不是烹饪。照片、评价、备注可选；成品照默认归该次记录。手动做后调整，轻量旧/新快照，不做版本树。不同做法可保存为同名不同菜谱。删除五秒撤销，截止前保留关联数据，结束后永久清理；不误删共享或历史仍引用的图片。

## 边界

Local-only，核心不登录、不联网，Android SQLite 是权威，图片私有文件；浏览器仅用于当前开发/验收，复用已有 IndexedDB 适配层。同一业务接口，不把浏览器结果冒称原生验收。数据不自动同步。完整手动备份先于继续积累重要数据和 AI。

AI 只在主动录入/找新做法时联网，预览确认才写正式库。区分原文、推断和用户修改，密钥不入 APK/普通备份。网页 parser-first；受限链接失败回退文字、截图、文件，不承诺万能解析。

不恢复：收藏、购物清单、菜单/计划提醒、推荐、行为追踪、复杂标签、内置计时器、云账号或长期回收站。未到相应模块不提前安装 AI/视频/备份依赖。

- 详情显示做过次数、上次日期和最近几次；按日期倒序分页的单菜谱历史显示照片、评价和备注。单次记录删除不删菜谱；菜谱沿用五秒撤销，截止前保留全部关联数据/文件，无回收站。
