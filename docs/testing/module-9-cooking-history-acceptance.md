# 模块 9：烹饪历史与个人改进验收记录

## 验收范围

本模块覆盖引导烹饪完成后的复盘保存、私有成品照片、周菜单联动和菜谱详情历史摘要。通知、远程推送、离线历史同步和记录编辑不在本模块范围内。

## 验收前置

- 使用已登录的测试账号和模块 9 对应的 Preview 部署。
- 目标 Supabase 项目已由负责人明确确认，并在远程执行 `20260831094439_cooking_history.sql`。
- 准备一个包含至少三步的菜谱，以及一条目标份数为 4 的周菜单安排。

## 场景记录

| 场景 | 操作 | 预期结果 | 通过记录 |
| --- | --- | --- | --- |
| 普通完成 | 从菜谱开始引导烹饪，最后一步点击“完成烹饪”，不填写可选项并保存 | 出现“烹饪完成”，显示记录已保存；本地进度被清理，详情累计次数增加 | 待 Preview 验收 |
| 带复盘完成 | 第二次完成，选择 5 星、上传 2 张照片并填写“下次少放盐” | 保存成功；详情显示平均分、实际份数、两张签名照片和“下次注意” | 待 Preview 验收 |
| 周菜单联动 | 周菜单中点击“开始烹饪：…”，检查份数，再完成烹饪 | 份数采用菜单目标份数；菜单项自动变为“已完成” | 待 Preview 验收 |
| 上传失败恢复 | 让照片上传失败或断网后点击保存 | 显示重试；复盘字段和本地烹饪进度仍保留 | 待 Preview 验收 |
| 数据库失败恢复 | 让完成 RPC 返回错误 | 已上传对象被清理；不显示完成页，可重试或明确选择不保存退出 | 待 Preview 验收 |
| 删除关系 | 删除关联菜谱或菜单项后重新查看历史 | 历史记录仍保留标题快照，关联 ID 安全变为空 | 待 Preview 验收 |
| 用户隔离 | 使用第二账号访问第一账号的菜谱、记录和照片路径 | 无法读取或修改第一账号数据 | 待 Preview 验收 |
| 响应式与无障碍 | 手机/桌面视口切换，键盘选择星级，移除照片 | 大按钮、可见焦点、可访问名称和错误提示均正常 | 待 Preview 验收 |
