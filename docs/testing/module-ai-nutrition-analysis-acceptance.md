# AI 营养分析 Preview 验收清单

请在登录后的 Preview 地址执行以下检查。所有结果都是日常记录用的 AI 参考值，不是医疗或专业营养建议。

## 独立营养分析

1. 打开主导航“营养”，输入“200 克牛肉 + 100 克熟米饭 + 100 克西兰花”，份数填 2，点击“开始分析”。
2. 结果应同时显示总计、每份、食材贡献和参考可信度；空指标不应显示为 0。
3. 把熟米饭改成生米并重新分析，分析说明应反映生熟状态或对应假设。
4. 输入“200 克牛肉 + 适量油”，重新分析。油应出现在“未计入项目”，可信度应降低，不应静默猜一个油量。
5. 刷新页面，独立分析结果不应被保存或自动恢复。

## 菜谱编辑器

1. 打开新建或编辑菜谱，填写至少一个有明确用量的食材。
2. 点击“AI 营养分析”，应回填每份热量、蛋白质等可用字段，并标记为“AI 参考值”。
3. 修改或清空回填值后直接刷新，确认未点击“保存菜谱”时不会写入菜谱。
4. 点击“保存菜谱”后进入详情页，确认营养卡片显示保存后的每份参考值。
5. 食材名称全部为空时点击分析，应提示先填写食材且不发起分析请求。

## 来源导入

1. 用数量明确的图文、视频或链接导入，确认营养信息在同一次 AI 整理结果中出现，并标记为需要核对的 AI 参考值。
2. 用缺少关键用量的来源导入，确认对应字段为空、进入缺失或遗漏提示，并要求确认后才能保存。
3. 导入过程中只应有一次成功的 Qwen 请求，不应额外发起营养专用请求。

## 导航与原有功能

1. 手机底部导航和桌面侧边栏应显示“菜谱、计划、购物、营养、设置”，不再显示“收藏”。
2. 访问旧地址 `/favorites` 应自动跳转到 `/nutrition`。
3. 菜谱详情仍可编辑、移入回收站；回收站仍可恢复和永久删除。

## 响应式与恢复

- 在手机窄屏和桌面宽屏分别执行一次分析，输入、加载、错误和结果都应可读。
- 拒绝或暂时没有 AI 服务时，应显示中文错误和“重试”，页面不能白屏。
- 分析失败时再次修改输入并重试，应使用最新内容。
