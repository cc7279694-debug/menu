# 模块 7：提前准备事项验收记录

## 已实现范围

- 菜谱编辑器支持新增、排序、关联食材和删除提前准备事项；精确时间按分钟保存，也支持“提前一晚”等文字时间。
- 菜谱卡显示最长提前时间，详情和离线详情显示完整清单。
- 网页、图文、视频文案和截图导入会提取来源明确的腌制、浸泡、解冻、醒发、静置等准备要求。
- 开始烹饪前显示确认清单，逐项勾选后开始，或选择“仍然开始烹饪”跳过；确认状态仅保存在当前设备的本次会话中。
- 离线菜谱快照升级为 `dataVersion: 2`，保留提前准备数据；购物快照继续使用 `dataVersion: 1`。

## 固定验收样例

导入或手动录入后，应能看到以下三项：

```text
牛肉：加入生抽和淀粉抓匀腌制，提前 30 分钟
绿豆：加足量清水浸泡，提前 4 小时
面团：覆盖静置，提前一晚
```

## 浏览器验收清单

1. 在 `/recipes/new` 新增带分钟、小时和文字时间的准备事项，保存后在列表和详情确认摘要及排序。
2. 编辑菜谱并删除关联食材，确认对应准备事项仍保留且变为“不关联食材”。
3. 在 `/recipes/import` 分别用文字和链接导入，确认准备事项进入可编辑草稿，再保存菜谱。
4. 从详情进入烹饪，逐项勾选“开始前请确认”；另测“仍然开始烹饪”和现有步骤计时。
5. 打开离线菜谱详情，确认准备事项仍显示；离线购物清单保持可用。
