# 模块 8：周菜单与提前准备提醒验收

## 自动验证范围

- 周一至周日范围与早餐 08:00、午餐 12:00、晚餐 18:00 默认时间。
- 精确提前时间跨天计算、文字时间保留、即将开始/已到时间/已逾期状态。
- 同一天同一餐多道菜、菜单表约束、所有权外键、强制 RLS、匿名拒绝和跨用户隔离。
- 同一菜谱重复安排时汇总目标份数，完成或跳过的计划不加入购物清单。
- 浏览器通知不支持、拒绝授权和当前设备去重发送时的降级行为。
- 手机/桌面共用周视图、加载状态、空状态、错误提示和控件可访问名称。

## Preview 回归清单

1. 登录后打开 `/plan`，在同一天同一餐添加两道菜。
2. 刷新页面，确认时间仍按当前设备时区显示；编辑日期、餐次和开做时间后再次刷新。
3. 为带精确提前时间与文字提前时间的菜谱各创建计划，确认提醒不虚构文字时间。
4. 拒绝浏览器通知权限，确认页面和应用内提醒仍可正常使用。
5. 完成、跳过、恢复、重新安排和删除计划，确认状态正确。
6. 同一菜谱安排多次后生成购物清单，确认份数先汇总、文字用量仍保持独立。
7. 使用第二个账号确认不能读取或修改第一个账号的菜单。

## 上线边界

- 先在明确确认的 Supabase 项目执行 `20260831032930_meal_plan_entries.sql`。
- Preview 验收通过后，再单独确认是否发布 Production。
